# 主角修改版切帧

原始文件为桌面主角修改版.png，原样备份，1536×1536。
待机9帧，行走11帧（原图行走间距并不均匀）。导出资源为 cocos/assets/resources/hero 下 idle-0…8 和 walk-0…10，统一200×300、脚底y=286，不逐帧单独缩放。背景采用边缘连通色分离，相邻行走披风/阴影采用背景最短缝分割。生成脚本：scripts/extract-hero-v13.py（依赖 Pillow、NumPy）。

手部挂点及实际显示尺寸见 cocos/assets/scripts/game/hero.ts。H5和Cocos共用帧及参数。查看验证截图/角色-v1.3-切帧预览.png，注意原图各姿势高度本身存在轻微变化。
