# 炉火远征

根据已确定玩法整理的独立游戏开发版本。图片暂用程序绘制占位，后续可替换为用户提供的素材。原项目不受影响；本项目采用独立存档键 `forge-expedition-save-v1`。

## 开始试玩

双击本文件夹中的 **启动游戏.command**。浏览器将自动打开游戏，运行期间保留终端窗口。此电脑已安装 Python 3，试玩不需要先安装 npm 依赖。

默认地址为 http://127.0.0.1:4188/ 。端口被占用时自动分配其他端口，以终端显示地址为准；不同端口的浏览器存档彼此独立。不要直接双击 dist/index.html。电脑使用此地址；手机请使用启动终端显示的局域网地址。

- WASD / 方向键或虚拟摇杆移动，角色按装备自动近战或射箭。
- Q：范围技能；E：减伤技能；1 / 2：生命 / 魔力药剂。
- 「回到主页」需确认，放弃本局后随身装备、道具、安全箱内容和本局金币全部丢失，营地仓库保留。
- 缺少武器或护具时，回到营地会补发对应基础装备并自动装备。
- 第一局必须完成教学；放弃教学不会解锁普通难度。

## 当前测试配置

- 角色基础 100 HP、60 MP；生命药剂恢复 35，魔力药剂恢复 30。
- 额外测试攻击 +120，初始短剑总攻击 128。生产平衡时把 `COMBAT.bonusAttack` 改回 0。
- 每个存档首次启动一次性获得四种品质锻钢、韧革各 50 件，幸运粉尘和精炼晶核各 50 件；材料在营地仓库。
- 短剑 / 长剑 / 弓箭 / 锤子基础攻击 8 / 20 / 14 / 32，攻击间隔 0.5 / 1.6 / 1.2 / 2 秒。
- 短剑 / 长剑 / 锤子距离暂定 58 / 110 / 52（960×540 逻辑坐标），沿用 120° 前方群攻；弓箭全图锁定最近单体，箭矢命中后扣血。怪物仍仅近战。

## 项目内容

- `dist/`：已打包的独立 H5 试玩版，由启动脚本提供本地服务。
- `src/`：H5 界面与 Canvas 绘制。
- `cocos/`：Cocos Creator 3.8.8 工程；双击「打开Cocos工程.command」。
- `cocos/assets/scripts/game/`：两端共用的 TypeScript 战斗、结算、锻造、仓库、平台与存档规则。
- `cocos/assets/scripts/ForgeTideBootstrap.ts`：Cocos 原生绘制及触控界面。
- `cocos/assets/art/README.md`：后续美术素材约定。
- `游戏设计说明.md`：机制和当前数值。
- `tests/`：规则测试源码。

H5 试玩入口使用 Vite 构建；Cocos 工程提供同规则原生界面。此新文件夹未附带重新发布的 Cocos 构建产物，需在编辑器完成资源导入后构建。抖音接口已有隔离层，尚未完成抖音开发者工具或真机验收。

## 开发

### 武器种类（2026-10-28）

在「锻造台 → 打造武器种类」选择短剑、长剑、弓箭或锤子，再选择品质打造，消耗对应品质或更高品质的 3 份锻钢。到仓库装备后出战。原有测试材料可直接使用，不新增赠送装备、不清空存档。

精英/Boss 掉落与死亡奖励生成武器时，四种类型等概率；基础保底仍为短剑。旧短刃存档转为短剑并保留品质、强化、锻造次数和安全箱引用。武器攻击公式：基础攻击 +（品质−1）×4 + 强化等级×3，最低 1；测试角色额外 +120 保留，因此现阶段攻速优势会很明显。

雷、火、冰、风、土只预留属性分类，无战斗效果。参考截图与来源在 `美术参考/武器/`，不作为游戏素材打包。

```sh
npm ci
npm run dev
npm run build
npm run check:cocos
npm test
```

Cocos 构建：打开工程、等待导入完成后，使用 `cocos/build-web.json` 配置。CLI 返回完成不代表资源完整；可运行 `npm run verify:cocos-build` 检查 Cocos 构建中的场景和着色器。

当前版本为开发测试版：测试高攻击与材料赠送仍启用，正式发布前需要关闭测试补给入口并调整战斗数值。

## 手机试玩与布局

1. 电脑和手机连接同一个 Wi-Fi。
2. 若旧的试玩终端仍在运行，先按 Control+C 关闭，再双击「启动游戏.command」。
3. 在手机浏览器输入终端显示的局域网网址，例如 `http://192.168.x.x:4188/`，不要使用手机的 `127.0.0.1`。
4. 横屏游玩。电脑保持开机，试玩终端保持运行；如果 macOS 提示局域网连接权限，请允许。

手机界面隐藏桌面页头/页脚，为刘海和底部手势区域留出安全间距。场景保持 16:9 比例；营地菜单单独滚动，锻造和仓库使用单列布局，技能、道具和主要按钮增大触控面积。移动摇杆固定追踪一根手指，另一根手指可点击技能；触控取消或切后台时清除移动状态。转为竖屏和切换后台会暂停战斗，回到游戏后手动继续。

H5 使用每台设备各自的本地存档，手机不会继承电脑存档。首次在手机进入会获得测试材料。此版本仍需在实际 iPhone / Android 设备上进行兼容性验收；当前已完成编译检查，未声明真机测试通过。
